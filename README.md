# 📅 GUI Calendar Application (Tkinter)

A desktop calendar application built in **Python** using **Tkinter** and Python's standard `calendar` module. Enter any year to render a formatted 12-month calendar view in a dedicated window, complete with a built-in feedback/issue reporting action via `pywhatkit`.

---

## 📂 Repository Structure

- `main.py`: Tkinter GUI implementation for the yearly calendar viewer.
- `README.md`: Project documentation.

---

## ✨ Features

- **Instant Full-Year Calendar**: Renders all 12 months for any user-specified year in a clean monospace (`Consolas`) grid layout.
- **Interactive Tkinter Interface**: Simple launcher window with year input and dedicated calendar display window.
- **One-Click Feedback Action**: Integrated issue reporting button powered by `pywhatkit`.

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparsh0106/GUI-Calendar.git
   cd GUI-Calendar
   ```

2. **Install dependencies**:
   ```bash
   pip install pywhatkit
   ```

3. **Run the application**:
   ```bash
   python main.py
   ```
